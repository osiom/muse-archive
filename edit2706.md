# edit 27.06 — Campaign-page design brief

Bringing the **cocoex website's look & layout** into the campaign side of Muse
Observatory: the flow after you click **Explore** → the **list view** → a single
**campaign detail page**. The reference is the website's **Comet Collab toggle
section** — but we take its *design and layout only*, **not the interactive
toggle mechanic** (the filter already separates Stardust from Horizon).

Goal: the archive should read as a sibling of the main site, and be **accessible
to disabled users** on every screen.

---

## The look we're borrowing (from the toggle section)

- **Background** — warm off-white `#FAFAFA`, bright and clean.
- **Type** — Canela serif. Huge uppercase titles (scales ~48→96px), tight line
  spacing. Small uppercase eyebrows/labels with wide letter-spacing.
- **Colour** — each campaign's muse colour as a quiet accent (not body text).
- **Signature** — the **liquid-glass "beam"**: a frosted-glass surface over a
  slowly-spinning rainbow of the 7 muse colours. We use it **once per page**, as
  a single hero accent, so it stays special.
- **Layout** — the toggle's **two-column editorial** rhythm: words on one side,
  a numbered sequence on the other.

---

## 1 · List view → "the archive"

Today it's a plain row list. We turn the light list mode into a proper archive:

- Off-white canvas, Canela, generous breathing room.
- A section header up top: small uppercase eyebrow + a large serif title.
- One **spectrum beam** as a thin animated rule under that title — nowhere else.
- Rows keep their three lines (eyebrow · name · meta), gain a subtle
  **muse-colour accent** and a soft **glass hover** (a gentle nudge, no jump).
- Stays a real, semantic list — it's the accessible backbone of the whole view.

---

## 2 · Campaign detail page → two-column editorial

Today it's a single stacked page (title → facts → hero → text → gallery →
footer). We restructure to the toggle's two-column rhythm:

```
┌─────────────────────────────────────────────┐
│  STARDUST 001 · BIO-DIVERSITY · 2025         │  ← plain label, no toggle UI
│                                              │
│  CANTINE VOLPI         │   01  Choose        │
│  short story / lede    │   02  Create        │
│                        │   03  Raise         │
│  Artist   …            │   04  Impact        │
│  Partner  …            │                     │
│  NGO      …            │  (Horizon adds a    │
│                        │   "Future Lab" step)│
├─────────────────────────────────────────────┤
│           [ hero image + gallery ]           │  ← the one beam accent lives here
│                  prose …                     │
│                  footer                       │
└─────────────────────────────────────────────┘
```

- **Left** — big uppercase title, a short story, then the existing facts block.
- **Right** — the campaign as **numbered steps**, styled like the toggle.
  Horizon simply has one extra step (Future Lab) with a small text badge — it's
  a normal list item, not a switch.
- **Hero + gallery** keep today's swipe/dot behaviour, reskinned to off-white +
  glass. The hero is where the single beam accent goes.
- **Footer** unchanged (dark, mission line).
- Two columns on wide screens; **stacks into one column on mobile**.

---

## Accessibility (non-negotiable, every surface)

- **Reading order = visual order.** The detail page is written title → story →
  facts → steps in the markup, so screen-reader, keyboard and no-CSS users get a
  clean single-column story. Columns are done with layout CSS, not reordering.
- **Never colour alone.** Type (Stardust/Horizon) and cause always have a text
  label, not just a hue.
- **Contrast.** Muse colours only for accents and big display type; body copy
  stays near-black on off-white. Each muse colour spot-checked on `#FAFAFA`.
- **Readable glass.** Any text over the frosted beam keeps its mute so it stays
  legible.
- **Motion.** The spinning beam and all hovers/gallery motion **freeze** when
  the OS "reduce motion" setting is on.
- **Keyboard & semantics.** Real list, real headings, image alt text, visible
  focus rings, gallery operable by keyboard.

---

## Out of scope

- The interactive toggle mechanic · any new per-type visual system beyond a label
  + the Future Lab step.
- ~~The globe (frozen)~~ — **amended**: the **dormant-muse CTA discs** (decision
  **G-H**) are a sanctioned layer-4 extension of the globe. The 4 causes with no
  campaign yet (Water · Rewilding · Renewable Energy · Zero Hunger) become **repeated
  muse-symbol CTA discs** that fill the globe's surplus vertices — each flips to a
  muse-name invitation + a `mailto:` to start a campaign; the list view carries the
  same invitation for keyboard/screen-reader parity. G-D's freeze condition was
  satisfied long ago (layers 1–3 are solid), same rationale as the V-3/V-8 flip work —
  this is art-pass polish, not a reopening of device-polish.
